### 3.4. Ответы на контрольные вопросы

1. **Какие команды используются для изменения владельца и группы файла?**
   - `chown` — изменение владельца
   - `chgrp` — изменение группы

2. **Что означают права доступа 770?**
   - Владелец: `rwx` (7)
   - Группа: `rwx` (7)
   - Остальные: `---` (0)

3. **Что такое SGID и зачем он нужен?**
   SGID — специальный бит, при установке на каталог новые файлы наследуют группу-владельца каталога, а не группу создателя.

4. **Что такое Sticky bit?**
   Sticky bit — специальный бит, при установке на каталог удалять файлы может только их владелец (или root). Используется в общих каталогах, например `/tmp`.

5. **Что такое ACL и зачем они нужны?**
   ACL (Access Control List) — список управления доступом, позволяющий задавать права для конкретных пользователей и групп, выходя за рамки стандартной модели `rwx`.

6. **Как установить ACL для группы?**
 setfacl -m g:groupname:permissions /path
7. **Как установить ACL по умолчанию?**
setfacl -m d:g:groupname:permissions /path
8. **Как посмотреть текущие ACL?**
getfacl /path
9. **Как удалить ACL?**
setfacl -x g:groupname /path
10. **Какая команда гарантирует, что никто не сможет удалить файл myfile случайно?**

Установка sticky bit на каталог:
chmod +t /path/to/directory
