3.2. Выполнение работы

3.2.1. Управление базовыми разрешениями

1. Создание каталогов /data/main и /data/third Выполнена команда sudo mkdir -p /data/main /data/third и просмотр владельцев через ls -Al /data.

2. Изменение владельцев каталогов Выполнены команды sudo chgrp main /data/main и sudo chgrp third /data/third. Проверка через ls -Al /data.

3. Установка разрешений 770 Выполнены команды sudo chmod 770 /data/main и sudo chmod 770 /data/third. Проверка через ls -Al /data.

4. Проверка доступа пользователя bob к /data/main Под пользователем bob выполнен переход в /data/main и создан файл emptyfile.

5. Проверка доступа пользователя bob к /data/third Под пользователем bob предпринята попытка перейти в /data/third и создать файл. Получен отказ в доступе.

3.2.2. Управление специальными разрешениями

6. Установка SGID и Sticky bit Выполнены команды sudo chmod 2770 /data/main и sudo chmod 1770 /data/third. Проверка через ls -ld.

7. Проверка SGID Под пользователем alice создан файл в /data/main. Проверено, что файл наследует группу main.

8. Проверка Sticky bit Под пользователем bob создан файл в /data/third. Под пользователем carol предпринята попытка удалить этот файл. Получен отказ.

3.2.3. Управление расширенными разрешениями с использованием ACL

9. Установка ACL Выполнены команды sudo setfacl -m g:third:rx /data/main и sudo setfacl -m g:main:rx /data/third. Проверка через getfacl.

10. Проверка ACL для нового файла Создан файл newfile1 в /data/main. Проверено наследование ACL через getfacl.

11. Установка ACL по умолчанию Выполнены команды sudo setfacl -m d:g:third:rx /data/main и sudo setfacl -m d:g:main:rx /data/third. setfacl -m d:g:groupname:permissions /path

12. Проверка наследования ACL Создан файл newfile2 в /data/main. Проверено автоматическое наследование ACL через getfacl. getfacl /path

13. Удаление ACL Для удаления записи ACL используется команда: setfacl -x g:groupname /path 14. Защита файла от случайного удаления Чтобы никто не смог случайно удалить файл myfile, необходимо установить sticky bit на каталог: chmod +t /path/to/directory

3.4. Ответы на контрольные вопросы

  1. Какие команды используются для изменения владельца и группы файла?

    • chown — изменение владельца
    • chgrp — изменение группы

  2. Что означают права доступа 770?

    • Владелец: rwx (7)
    • Группа: rwx (7)
    • Остальные: --- (0)

  3. Что такое SGID и зачем он нужен? SGID — специальный бит, при установке на каталог новые файлы наследуют группу-владельца каталога, а не группу создателя.

  4. Что такое Sticky bit? Sticky bit — специальный бит, при установке на каталог удалять файлы может только их владелец (или root). Используется в общих каталогах, например /tmp.

  5. Что такое ACL и зачем они нужны? ACL (Access Control List) — список управления доступом, позволяющий задавать права для конкретных пользователей и групп, выходя за рамки стандартной модели rwx.

  6. Как установить ACL для группы? setfacl -m g:groupname:permissions /path

  7. Как установить ACL по умолчанию? setfacl -m d:g:groupname:permissions /path

  8. Как посмотреть текущие ACL? getfacl /path

  9. Как удалить ACL? setfacl -x g:groupname /path

  10. Какая команда гарантирует, что никто не сможет удалить файл myfile случайно?

Установка sticky bit на каталог: chmod +t /path/to/directory
