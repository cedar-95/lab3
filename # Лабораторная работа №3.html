Цель работы

Получение навыков настройки базовых и специальных прав доступа для групп пользователей в операционной системе типа Linux.

Среда выполнения

  • ОС: Rocky Linux 10.2

  • Оболочка: Bash

  • Инструменты: chmod, chgrp, setfacl, getfacl

  • Управление базовыми разрешениями

  • Создание каталогов /data/main и /data/third

  • Изменение владельцев: chgrp main /data/main, chgrp third /data/third

  • Установка разрешений 770: chmod 770 /data/main, chmod 770 /data/third

  • Проверка доступа пользователя bob

  • Управление специальными разрешениями

  • SGID: chmod 2770 /data/main — новые файлы наследуют группу каталога

  • Sticky bit: chmod 1770 /data/third — удалять файлы может только владелец

  • Проверка SGID под alice

  • Проверка Sticky bit под carol

  • Управление ACL

  • Установка ACL: setfacl -m g:third:rx /data/main

  • Установка ACL: setfacl -m g:main:rx /data/third

  • Просмотр ACL: getfacl /data/main, getfacl /data/third

  • ACL по умолчанию и наследование

  • Установка: setfacl -m d:g:third:rx /data/main

  • Установка: setfacl -m d:g:main:rx /data/third

  • Проверка наследования: getfacl /data/main/newfile2

  • Удаление ACL и защита файлов

  • Удаление ACL: setfacl -x g:groupname /path

  • Защита от случайного удаления: chmod +t /path/to/directory (sticky bit)

  • Вывод

В ходе лабораторной работы были изучены механизмы настройки базовых и специальных прав доступа в Linux. Освоены команды chgrp, chmod, getfacl, setfacl. Изучены механизмы SGID, Sticky bit и списков ACL.
